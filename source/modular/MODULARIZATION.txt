Goal
----
This is a layout-preserving INCLUDE split. No source line from the original was edited,
reordered, normalized or reformatted inside the modules. The modules are contiguous
byte ranges of the released c87b80o source and remain in the exact original order.

GloomReforged_Recombined.s is the literal concatenation of gr_00..gr_24. It is verified
byte-for-byte identical to the uploaded GloomReforged.s.

GloomReforged_Modular.s contains only GenAm INCLUDE directives, in the same order.
All include files are deliberately kept in the same directory as the master file. This
keeps the existing relative INCBIN names (arc.bin, gridoffs4.bin, sqr.bin, etc.) in the
same source-directory context as the monolithic build.

Module boundaries were chosen only where conditional-assembly, MACRO and REPT nesting
is at depth zero. Hot routines were not relocated; therefore code/data order and all
branch/PC-relative distances are intended to remain exactly unchanged after INCLUDE
expansion.

GenAm test on the Amiga
-----------------------
1. Keep the original GloomReforged.s unchanged as the v2.0 reference.
2. Put GloomReforged_Modular.s and all gr_*.s files in the same directory as the
   original source and its INCBIN assets.
3. Assemble the original source and save the executable as GloomReforged_MONO.
4. Assemble GloomReforged_Modular.s with exactly the same GenAm 3.18 options and save
   the executable as GloomReforged_MOD.
5. Compare file size and preferably a binary checksum. With debug/line-information
   output disabled, the executable should be byte-identical because INCLUDE is textual.
   If debug/line source information is enabled, source-file metadata can make the final
   executable differ even when CODE/DATA hunks are identical.

Important
---------
This first pass intentionally does NOT move routines into new semantic order. Doing so
would change addresses and may create/remove GenAm PC-relative and short-branch range
issues. Once this INCLUDE build is proven, individual modules can be cleaned internally
one at a time with separate regression tests.
